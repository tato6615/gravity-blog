# 07_IDEAS

## Purpose
A low-friction capture point for raw, unfiltered ideas — before they are
evaluated, scoped, or scheduled. This is intentionally messy and fast.
Nothing here is a commitment.

## Relationship to 05_ROADMAP
- `07_IDEAS` = unstructured, unscored, "might be worth doing someday"
- `05_ROADMAP` = scoped, prioritized, scheduled

An idea graduates from here to the roadmap only after it's been reviewed and
given a real scope. Until then, it stays here so it doesn't pollute planning
docs — this directly enforces Objective #4 (Ideas must not be mixed with tasks).

## Structure
```
07_IDEAS/
  INBOX.md         → running capture list, newest on top, no formatting required
  EXPLORED/         → ideas that got a deeper look (one .md file per idea)
  REJECTED.md       → ideas explicitly decided against, with a one-line reason
                      (prevents re-litigating the same idea every few months)
```

## Workflow
1. Drop the idea into `INBOX.md` the moment it occurs to you. One line is fine.
2. During a periodic review, either:
   - Promote it → move scoped version into `05_ROADMAP/BACKLOG.md`
   - Explore it → give it its own file in `EXPLORED/`
   - Kill it → move the one-liner to `REJECTED.md` with a reason
3. `INBOX.md` should stay short — it's a buffer, not a graveyard.
