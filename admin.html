Import Product

วาง URL สินค้า หรือพิมพ์รายละเอียด แล้วให้ AI จัดการที่เหลือทั้งหมด

Generate Everything

AI จะสร้างข้อมูลทุกอย่างให้อัตโนมัติ — วิเคราะห์สินค้า, คีย์เวิร์ด, เนื้อหา SEO, โพสต์โซเชียล, และ prompt รูปภาพ

    Publish

    ข้อมูลพร้อมครบทุก Table แล้ว เลือกช่องทางที่เผยแพร่ แล้วกด Publish เพื่อยืนยัน

    สรุปข้อมูลที่บันทึกแล้ว

    Import → Generate Everything → Publish · ทุกอย่างที่เหลือ AI ทำ

    รายการสินค้าทั้งหมด

    ดูสินค้าทุกชิ้นที่เคย Import ไว้ พร้อมสถานะ — ลบทิ้งได้ถ้าไม่ต้องการแล้ว (ลบแล้วกู้คืนไม่ได้ ข้อมูลทุก table ของสินค้านั้นจะหายไปด้วย)
    กด "รีเฟรชรายการ" เพื่อโหลดข้อมูล
